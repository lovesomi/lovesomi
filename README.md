# 7년 차 백엔드 & 인프라 개발자

안녕하세요!  
**백엔드 개발을 기반으로 인프라·보안·DevOps까지 직접 경험해온 개발자**입니다.

ERP, MES, 커머스, 공공·폐쇄망 환경 등 다양한 프로젝트에서
